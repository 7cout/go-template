# go-conventions

Основа — Go Code Review Comments и Effective Go; подробности и источники — вики `C:\7cout\ai\knowledge\wiki\go-*.md`.

## Ошибки
- Ошибку не выбрасывать (`_ =`, пустой `if err != nil {}`); обработал — сразу `return`.
- Контекст в обёртке: `fmt.Errorf("create item: %w", err)`. Сравнение — `errors.Is/As`, не `==` и не по строке.
- Ошибки драйвера/библиотеки на границе адаптера не оборачивать `%w` (раскрывает реализацию): мапить в доменные (`pgx.ErrNoRows` → `domain.ErrNotFound`) или `%v`.
- Текст ошибки — с маленькой буквы, без точки. panic — не для обычных ошибок.

## context
- `ctx context.Context` — первый параметр; не хранить в struct; `context.Background()` только в `main`/тестах (в тестах — `t.Context()`).
- `WithTimeout`/`WithCancel` → всегда `defer cancel()`.

## Интерфейсы и типы
- Интерфейс объявляет потребитель (`internal/app`), маленький, без «на будущее».
- Конструктор возвращает **конкретный тип** (`*Items`), интерфейс — только когда скрыть реализацию — цель API.
- Получатель: короткое имя по типу, одинаковое во всех методах; сомневаешься — указатель.

## Тесты
- Table-driven: слайс кейсов с `name`, `t.Run(tt.name, ...)`, `t.Parallel()` где можно.
- Сообщение: `Func(%q) = %v, want %v`. `t.Errorf` по умолчанию, `t.Fatalf` — если дальше нет смысла.
- Хелперы с `t.Helper()`, уборка — `t.Cleanup`, временные файлы — `t.TempDir()`.
- Внешний пакет `_test` для тестов публичного API.
- Всегда `-race`.

## Конкурентность
- Синхронные функции по умолчанию; у каждой горутины понятный конец (`ctx`, закрытие канала).
- Общие данные — `sync.Mutex`/`RWMutex` или `sync/atomic`; `sync.WaitGroup.Go` для групп.

## pgx / SQL
- Пул `pgxpool` в сервисе; `*pgx.Conn` не потокобезопасен.
- Запросы — через sqlc (`db/queries` → `task sqlc`); сгенерированное не править.
- Транзакции — `pgx.BeginFunc` или `defer tx.Rollback(ctx)` + `Commit`.
- `rows.Close()` всегда (или `pgx.CollectRows`).

## Стиль
- Форматирование делает хук (goimports + gofumpt). Имена: MixedCaps, `URL`/`ID` в одном регистре, пакет — одно слово, не `util`.
- Doc-комментарий у экспортируемых имён: полное предложение с имени.
